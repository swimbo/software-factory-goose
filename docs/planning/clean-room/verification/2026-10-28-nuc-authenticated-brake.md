# NUC authenticated independent brake fixture

`python3 clean-room/tests/fixtures/nuc_authenticated_docker_brake_spike.py` passed on nuc-hermes. The actual Rust BrakePolicy/Unix peer middleware served one fixed opaque target backed by its exact labelled Docker worker and durable manifest/slice identity. A distinct networkless, nonroot UID1002 client received only the socket and an ephemeral synthetic credential, not Docker access. UID1003 with the correct key, UID1002 with a wrong key, and an unknown target were refused without stopping the worker. The correct UID1002/key pair requested cleanup; pending replies were polled until verified, then a repeated request returned the same verified result without reissuing cleanup. The worker was absent and the same persistent slice inode reported populated0. No journal or inference gateway was used by this stop path.

The fixture compiled in an owned temporary NUC directory using an isolated Cargo home, two build jobs, debug disabled and public locked crates. OpenSSL development headers were downloaded and unpacked under that directory, not installed; shared runtime libraries were used. A failed initial attempt without those headers is an environment prerequisite failure. The final fixture cleans its owned build, sources, key, relay, worker, anchor and test clients. Existing Hermes dashboard, Hermes gateway and Docker remained active; no task user units or brake-labelled containers remained.

This is not production operator provisioning or durable stop-state recovery. Numeric container UID separation and a synthetic mounted key demonstrate the tested authentication boundary. The host user retains Docker authority, socket ownership/lifecycle and credentials need trusted provisioning, and manager/daemon loss, all-path migration denial and production supervisor recovery remain open. The fixture stop state is in memory. Cleanup has a bounded child and pending/verified/unknown reconciliation; a daemon mutation already accepted before timeout cannot be canceled or assumed undone.
