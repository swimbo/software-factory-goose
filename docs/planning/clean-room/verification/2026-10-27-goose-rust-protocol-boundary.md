# Goose request validation prototype

The new unregistered Rust `goose_protocol` module checks the two request shapes observed in the restricted Goose synthetic proxy spike: system/user messages, followed optionally by one assistant function call and its matching tool result. It requires an exact configured model and trusted tool schema, a bounded serialized request, a positive bounded output token value, streaming with usage enabled, and no unreviewed top-level fields. Unsupported roles, malformed arguments, changed schema, mismatched IDs and oversized requests reject. The function performs no inference, reservation, socket binding or worker activation.

The focused three-test suite initially failed to compile because the validator did not exist; after implementation all three passed with `cargo test --offline --locked -p control-plane --all-features --lib goose_protocol`. `cargo clippy --offline --locked -p control-plane --all-features --lib -- -D warnings` passed. The tests use synthetic values shaped like the observed protocol; they do not invoke Goose through this Rust module.

The bounded raw-byte entry point now checks size before parsing and rejects duplicate keys at every JSON object depth, including inside the tool-call arguments JSON string. A second test-first negative control exposed duplicate keys in that embedded string; its parser was corrected and the control passed. The test-only reservation fixture now uses this raw entry point and verifies ambiguous requests trigger neither reservation nor provider call. Eight focused Goose protocol and reservation tests passed.

The check does not authenticate clients or correlate submitted tool history with an earlier trusted provider response. It has no response/SSE validation, real per-call reservation, review expiry, gateway routing or provider integration. The existing text-only `GatewayClient` remains unchanged and fail-closed for tools. A separate authorized runtime must establish those boundaries and provider billing limits before accepting this prototype as a production path.
