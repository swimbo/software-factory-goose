# Inherited gateway listener checkpoint

Bifrost commit `c14651e` adds a Linux handoff for a supervisor-supplied listener descriptor. The gateway duplicates the supplied descriptor with close-on-exec, checks the kernel-reported Unix socket address, stream type and listening state, and consumes its inherited copy before serving. The launcher must close its own copy after handoff. The handoff does not authenticate the launcher or establish ownership of the pathname.

In a network-disabled Linux container, inherited-listener, listener and protocol tests passed under Go's race detector. They cover wrong paths, regular files, TCP, connected non-listening sockets, closed descriptors, descriptor consumption and an actual descriptor transfer across `exec`. The cross-process test uses synthetic same-user processes and a temporary socket.

A separate fresh, network-disabled wallet rehearsal used the inherited-listener code with the actual wallet, Root scope methods, broker, Bifrost handler, physical capture and collector. It settled one synthetic provider call before the parent cancelled the gateway. The gateway test binary SHA-256 was `980f4337684c1a57d8050a2d65858bca77ec6e66e1752108244bb143e734d0cc`; the handoff source SHA-256 was `5ebf022e6b2fc8a16c4c424bcd742ba843bac47681f580d6ea4cbbe73f6cd4e9`. The exact pinned source preimage was reconstructed and the updated installer installed the handoff and test files. Eight installer tests and Ruff passed. The isolated stage is `/home/bo/sfactory-wallet-listener-Wlvaz9Wy` on `hermes-control`; the exact test containers exited and were absent.

The wallet rehearsal passes a duplicated descriptor within its synthetic gateway process; it does not run the actual supervisor launch. Root construction, registry, route, authorizer, provider, tariff and charge bounds are synthetic. The chroot does not prove live socket pidfd acquisition. Production bootstrap, route custody, all-path charge bounds and owner/daemon/host loss cleanup remain open. No paid inference or candidate activation occurred; the benchmark remains at 0/120.
