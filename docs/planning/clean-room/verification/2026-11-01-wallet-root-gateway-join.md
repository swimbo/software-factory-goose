# Isolated wallet, Root and Bifrost join

A network-none, distinct-UID fixture joined the durable Rust spending journal and private ingress, actual Root scope methods over a Root-authenticated Unix socket, the protected broker transport and one-use acquisition, the actual Bifrost inference handler, SQLite physical capture, and the independent usage collector. The test reserves the synthetic route bound, dispatches one local synthetic provider call, closes and audits its capture, settles the same wallet, and verifies a repeated begin is denied after completion. A changed Root scope and a worker connection to the Root socket are refused. The synthetic Root lease deadline is observed in the preimage; expiry enforcement is covered separately by the [gateway deadline fixture](2026-11-01-root-stream-deadline.md).

The [raw fixture receipt](2026-11-01-wallet-root-gateway-join.json) records binary and source hashes. An independent read of the final SQLite database found one sealed, complete capture, one answer call with one input and one output token, an unused fallback, and a one-microusd audited synthetic cost. The exact owned container was absent after exit. The wallet runtime matches the previously recorded native binary; its recorded wallet source differs from the current file only by an added test assertion. Bifrost fixture source and installer are published at `253cf20`. The pinned installer was replayed against its verified pre-exchange source; gateway and handler race tests, seven installer tests, 53 focused Python tests, and fixture lint passed. Independent reviews identified test-receipt and provider-count gaps; each was corrected, rechecked and exercised in a fresh final run.

The catalog, registry gate, Root construction, route, provider, final-wire authorizer, tariff and charge bounds are synthetic. The fixture does not establish the dedicated production bootstrap, real provider costs, full Root launch or process/descendant cleanup. It performs no paid inference or candidate activation. **Actual benchmark attempts remain 0/120.**

The wallet code enforces the $5 UTC-day and $0.75 permanent-task reservation ceilings. Before live dispatch, the reservation must also cover every possible provider charge; the synthetic bound here does not establish that property for the retained hosted routes.
