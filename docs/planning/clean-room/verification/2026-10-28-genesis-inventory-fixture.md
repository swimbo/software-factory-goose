# Fresh namespace inventory fixture — 2026-10-28

This is an unregistered Restate object prototype for a possible fresh dedicated deployment, not a migration or production bootstrap. It issues task IDs only as `<namespace ULID>_<server-generated ULID>` after explicit bootstrap. Its bounded inventory binds a canonical request ULID and intent ULID to each task, rejects caller-supplied task IDs and unknown fields, fails on collision or inconsistent stored records, retains 128 entries without eviction, and preserves exact retries. Membership requires an actual inventory entry, not a matching prefix.

The first test-first run failed because the inventory API did not exist. After implementation, `cargo test --offline --locked -p control-plane --all-features --lib genesis_fixture::tests::` passed 5 tests: issuance/replay and request conflicts, foreign/forged task IDs and invalid namespace, corrupt history, collision with no mutation, full-capacity retry/no eviction, and rejection of caller-supplied task IDs. `cargo clippy --offline --locked -p control-plane --all-targets --all-features -- -D warnings` passed before the final test-only addition. These are local in-memory state tests, not Restate crash/replay or deployment tests.

A new isolated deployment with no pre-existing factory tasks could avoid an old-task migration for its own IDs, but this fixture alone does not prove an installation is new, that historic or fixture objects are absent, or that legacy endpoints and other ledgers cannot still issue/spend. `bootstrap` can recreate empty state after complete state loss; an independent durable genesis seal and verified recovery protocol must prohibit unsafe recreation before this can enforce exclusivity. The object has no authenticated ingress or instance binding; no production claim, queue, budget, inference, or promotion handler consults membership. Namespace uniqueness, trusted task provenance, atomic handoff, full authoritative inventory, private listener and recovery/restore verification remain open. No existing instance, service, account, data, or production namespace was modified.
