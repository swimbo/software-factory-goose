# Blocked router deadline

The private gateway now waits for the real router only until its acquired Root context expires or is cancelled. If the router has not returned, the exchange fails and the gateway is poisoned; it cannot be reused. The router goroutine may still be running. A separately qualified supervisor must fence, kill and join the gateway process and its descendants before any subsequent attempt; this change does not establish that cleanup.

A distinct-UID, network-none native regression blocked the router after a synthetic physical call. The original handler failed to return before the client timeout. The revised handler refused the exchange at the Root deadline, produced no capture acknowledgement, and denied reuse; this test also passed with Go's race detector. Four other native cases passed: v2 success, a blocked stream at deadline, a stream-close error, and an invalid response with blocked close. The actual Bifrost handler also passed the joined wallet, Root, broker, capture and collector fixture with a synthetic provider. The final source passed gateway tests under the race detector, the installer tests, and a reconstruction and replay of the pinned installer. The [receipt](2026-11-01-blocked-router-deadline.json) records hashes and fixture boundaries.

Bifrost source commit: `f726ca7`. These tests use synthetic routing, authority configuration and charge bounds. They do not establish production gateway bootstrap, egress fencing, owner/daemon/host-loss cleanup, or provider cost bounds. No paid benchmark attempt ran and the candidate remains disabled.
