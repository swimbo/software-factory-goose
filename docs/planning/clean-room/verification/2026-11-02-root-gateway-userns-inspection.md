# Root gateway user-namespace inspection

The Root supervisor has a private, read-only `inspect_gateway_user_namespace` primitive. Given a trusted child PID/start time and independently pinned namespace device/inode, it verifies the child remains unreaped and direct, the namespace is a distinct direct child of Root's user namespace with Root as owner, the UID/GID mappings are exactly the synthetic Root/gateway/broker mapping, and the gateway identity has no groups or capabilities, no-new-privileges and seccomp mode 2. It rechecks child and namespace identity. Namespace relationships and ownership use the Linux [namespace ioctl interface](https://man7.org/linux/man-pages/man2/ioctl_ns.2.html).

In a network-disabled x86-64 fixture the actual verifier accepted the filtered synthetic gateway and refused a changed namespace inode, gateway UID and broker GID. The real barrier, post-exec same-UID attack controls, socket replacement and synthetic broker peer check were replayed in the same fixture. The controller used `CAP_SYS_ADMIN` to inspect namespace ancestry; the target had no capabilities. The configured Python suite ran 275 tests with seven skipped before a final verifier recheck ordering adjustment; the native replay and 29 focused gateway tests (one skipped) passed afterward. An initial unconfigured suite failed because the QuickJS host environment was absent; the configured rerun passed.

This is **point-in-time evidence**, not a lifetime fence or production authorization. The private launcher does not yet create, pin or call this verifier; its namespace receipt in the fixture came from the synthetic controller. Namespace creation, exact-map publication, namespace continuity, exclusive membership, actual Root lifecycle, egress and loss cleanup still require implementation and qualification. A changed supervisor source digest must be reviewed and bound by a future production configuration. No paid calls or candidate activation occurred; live attempts remain 0/120 and the $5/day and $0.75/task caps remain binding.
