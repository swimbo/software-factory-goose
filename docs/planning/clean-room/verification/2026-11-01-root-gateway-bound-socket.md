# Root gateway bound socket checkpoint

`linux_gateway_socket.py` creates a non-listening per-attempt Unix socket under `/var/lib/sfactory-harness/gw`, with a full attempt digest in its name. It requires Root, root-owned non-writable ext4 ancestors without POSIX ACLs, checks pathname identity, and sets the socket owner to the gateway UID, group to the broker GID and mode to `0660`. Existing or ambiguous paths are never replaced or automatically removed. Ancestors must be traversable and readable by both services because the existing broker opens them read-only.

The Root supervisor has an internal one-use binding method: it checks the current grant, scope, cgroup and PID1 guard, durably records intent, binds, repeats the current-grant and guard checks, then records the socket identity. A failed post-bind check closes the descriptor and retains the intent. Root schema 4 requires the helper's reviewed SHA-256; both harness profiles include it. Schema 3 remains accepted for the existing peer check but cannot invoke the new binder. The method has no RPC endpoint and is not yet called by a gateway launcher.

It verified a non-listening Root-bound socket, rejected a writable parent and repeated binds, and observed the gateway PID and UID at the broker. The test used synthetic attempts and no provider.
