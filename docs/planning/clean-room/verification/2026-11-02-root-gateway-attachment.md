# Root gateway attachment source checkpoint

The private `_attach_gateway` method binds a gated child attachment to schema 4, the saved socket creation and handoff receipts, current scope, cgroup checks and the independently observed guard. It records a one-use leaf intent before attachment, durably records the exact created inode before the move, rechecks scope and guard, and records the child identity after success. It does not spawn the child, release the gate, or expose production admission.

Focused component tests use synthetic files, a mocked kernel attachment and a mocked guard. They cover a changed socket receipt, guard loss before and after the move, durable receipt ordering and duplicate attachment denial. Supervisor SHA-256: `79319a70fa5a732d9b53f6c639621289fccf281f2450d1a9bbc24a8330c7bfec`. The underlying attachment primitive previously passed a separate native cgroup and PID1 fixture, but this new composed method has not been exercised against production Root, real socket handoff or the real gateway.
