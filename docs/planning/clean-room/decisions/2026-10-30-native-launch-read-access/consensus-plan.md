# Native launch access — three-reviewer conditional consensus

Choose revised A. Root owns each callback parent, group2000, mode0710; the control
service gets search permission through its tested O_PATH traversal and cannot
replace the socket. Native model UID2001 must fail child lookup/connection on the
host. Docker binds only the root-created socket. Keep native launcher and all
worker/service capabilities empty; the earlier read-search probe is diagnostic,
not the selected production profile. It did not prove the original error's sole
cause. The failed generation stays closed and reserved.

Security, Rust operations and contrarian reviewers independently accept this
conditional choice (security.md, operations.md, contrarian.md). Reject broad DAC
or ptrace. Do not adopt B: it leaves the callback pathname replacement issue and
increases inherited privileges when the launcher only needs callback metadata.

Implementation gates:

1. Stop admission during a quiescent, versioned owned-package/helper upgrade. Pin
   old bytes and metadata, preserve root-only backups, fsync each exclusive temp
   and parent, change manifests last, and keep a durable upgrade intent. Mixed
   versions must refuse. No running launcher, open generation or pending start
   may cross the transition; no shared services or old generation are modified.
2. Update helper, relay listener validator, fresh preparer and native readiness
   together. Rebuild the native probe that currently requires capability4. Check
   E/P/I/B/A allzero and NNP in actual native execution and its fixed descendants.
3. Exclude trusted socket rebind from validation through Docker create, holding a
   root-owned lifecycle lock through the known operation and retaining quarantine
   on unknown outcomes. Recheck root directory and socket device/inode; equality
   alone is not exclusion. Reconciliation cannot stop/rebind while launch/create
   is pending. Kernel braking must remain independent of these locks.
4. Prove UID2000 actual listener validation/O_PATH traversal and denied parent
   mutation; UID2001 denied child lookup/connect. Opening an O_PATH descriptor to
   the parent itself is not a sufficient negative control. Recheck exact native
   units/images/inputs and the active ordinary operator brake before a fresh claim.

These are implementation/verification gates, not evidence of connected production
success, daemon/host-loss recovery, approved promotion or final delivery. The prior
root-supervisor and operator policy decisions otherwise remain in force.
