# Round 1 — application security

Date: 2026-10-27. Read [harness position](position-harness.md), [operations position](position-operations.md) and the [shared ledger](evidence-ledger.md). There is no substantive disagreement about activation: evidence supports an offline spike only. The remaining differences concern ordering, outcome classification and what a passing subtest proves.

**I maintain my position on testing executable discovery first.** Harness rightly identifies the fresh-session/no-profile behavior as a credible mechanism, while operations emphasizes configuration drift. These are complementary. Before constructing the full factory tool service, plant harmless marker-producing project hooks, attempt resume and return forbidden tool names from the scripted provider. A protected launch directory is an experiment variable, not an assumed solution. If any reachable hook, builtin, extension or subagent executes outside the intended boundary, the stock candidate is falsified under that configuration. The source basis remains [builder precedence](https://github.com/aaif-goose/goose/blob/71fc4be1ed729e26b1dc0a4466abdd03be548a53/crates/goose-cli/src/session/builder.rs#L568-L625) and [independent discovery](https://github.com/aaif-goose/goose/blob/71fc4be1ed729e26b1dc0a4466abdd03be548a53/crates/goose/src/plugins/discovery.rs#L154-L183). No expanding list of disabled plugin names substitutes for a closed boundary.

**I concede that uncertain side effects must be a first-class experiment outcome, not merely a security failure label.** Operations makes the stronger point: acknowledgement loss after a tool side effect creates a recovery problem even when no security policy was violated. The spike must distinguish explicit failure from unknown completion. A cancelled request is not termination proof under the [MCP cancellation contract](https://modelcontextprotocol.io/specification/2025-06-18/basic/utilities/cancellation). Keep the attempt quarantined until cleanup/reconciliation is established; a later response must not authorize a replacement attempt or release its reservation. This extends my prior fail-closed recommendation without changing O4 or the runtime architecture.

**I maintain source-side sanitization, while conceding that the first spike may refuse entire content classes.** Harness proposes this practical restriction and operations supports it. No requirement forces the experiment to support media, resource hydration or arbitrary notification payloads. It must prove direct requests are refused, however, rather than merely omit them from discovery. For supported text/errors, inject synthetic secrets into successful and failed results, split chunks and truncation boundaries. Inspect every recorder request and masked capture. The [pinned post-tool wrapper](https://github.com/aaif-goose/goose/blob/71fc4be1ed729e26b1dc0a4466abdd03be548a53/crates/goose/src/agents/state_machine/ops_toolcalling.rs#L237-L310) remains insufficient because it preserves the result and parallel streams.

**I maintain the unresolved R13 distinction.** Both reviewers accept that a permitted build can execute descendants. A passing tool-dispatch canary proves mediation of the tested tool requests; it does not establish that every descendant shell command passed the declarative command policy. Record the command-level and OS-effect guarantees separately. If literal descendant mediation remains required and absent, report that blocker even after all broker tests pass. Do not manufacture consensus by changing the acceptance wording.

The bounded spike is accepted only when a real pinned binary performs an allowed operation with an independently observed marker and subsequent provider request; tested forbidden surfaces produce no side effect; supported outputs are sanitized before Goose ingestion; disabled channels refuse direct calls; malformed policy/broker failure stops execution; cancellation and disconnect never yield successful receipts; and attempt, process, usage and revision observations reconcile. Synthetic zero-cost accounting proves classification behavior only, not live Bifrost spending accuracy.

Stop and preserve evidence on the first demonstrated bypass; diagnose its exact source path before proposing a patch. A narrow upstream-derived repair is acceptable as a contingency, but requires its own reproducible artifact and complete affected regression matrix. Even a passing experiment leaves activation blocked on distinct identities, network isolation, real accounting, independent supervision and exact-SHA verification. Evidence grade remains ADEQUATE for the spike and INSUFFICIENT for activation.
