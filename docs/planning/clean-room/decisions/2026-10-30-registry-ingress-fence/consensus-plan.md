# Registry ingress fence: conditional consensus

**CONSENSUS_REACHED — 2026-10-30.** Three approved reviewers completed current
research, independent positions and one focused round. All agree to test the
following direction. This selects a bounded experiment; live adoption remains
conditional on its result and an exact reviewed transition plan.

Use the installed pinned Restate1.8.0 binary with **Unix-only administration,
fixed Root-mediated administrative operations and permanent retirement of every
ungated SDK1–4 execution endpoint**. Keep ingress TCP for the gate-aware runtime.
Root, PID1, Docker and the UID2004 journal role remain trusted. No new human
authentication claim, service account, group membership or model policy follows.

The fixed Root-owned admin program may run as trusted UID2004 through PID1 to
reach Restate's private admin socket without widening its data permissions or
granting capabilities. Root initiates the exact operation, captures bounded pipe
output and stores Root receipts. No arbitrary SQL, URL, registration body, command
or descriptor may be selected by an untrusted caller. SDKUID2000 cannot reach
the underlying admin socket and receives no inherited admin connection.

Retire all old endpoint services and socket activation paths with persistent
Root-owned refusal markers and verified manager identities, terminal processes,
empty cgroups, no jobs and no surviving serving descriptors. Keep old binaries,
unit definitions, deployment metadata, claims, reservations and journal history.
Stopping an endpoint does not complete its old pinned invocations.

## Decisive disposable experiment

Use a new factory-owned namespace, fresh state root, pinned Restate, two synthetic
SDKs and fixed native probes under the real role UIDs with empty capabilities
and NNP. No production namespace, credentials, provider, shared service or data
is involved. Root intent and exact source/binary/unit pins precede effects.

1. Observe the exact admin Unix path, owners/modes/ACLs and listener configuration;
   prove TCP admin absent, SDKUID2000 denied and fixed trustedUID2004 operation
   permitted. Check no privileged descriptor is inherited by the SDK.
2. Establish a positive UID2000-to-ingress-to-old-SDK mutation and direct old
   listener reachability before retirement. Include a connection established
   before closure. No hypothetical nft installation is needed to prove this.
3. Create actual old pinned/in-flight, queued and delayed/unpinned work and
   completed history; record server-issued deployment IDs and actual queue rows.
4. Persist the retirement fence, stop the exact old endpoint and prove direct,
   reused and ingress-forwarded attempts cannot execute another old effect.
   Verify manager restart attempts cannot reactivate it.
5. Permit one non-force new registration through the fixed admin operation.
   Bind the server-minted ID to the durable attempt. Test lost response/unknown
   handling without another registration and preserve every old history.
6. Restart only owned fixture processes and verify Unix administration, retirement
   and retained-work classification persist. Loss or ambiguous cleanup keeps the
   attempt closed. Remove only exact owned resources after terminal proof.

This experiment need not reboot the NUC or destroy its real namespace. Those
boundaries require later non-disruptive recovery proofs and exact live planning.
If Unix configuration/permissions fail on the pinned binary, retain the failure
and reconsider scoped namespace filtering from that evidence. Do not silently
fall back to the exposed TCP admin path.

## Later live transition gates

Before a live change, inventory every admin client and retained invocation,
preserve a recoverable journal backup, and fsync a persistent closed transition
intent under the exclusive registry gate. Establish admin protection and old
endpoint retirement **before** the decisive queue/invocation observation.

True quiescence requires a tested zero predicate. Retained nonterminal work must
be explicitly enumerated as unavailable quarantine; it is not drained, completed
or migrated. Any overlapping unresolved work blocks ordinary release. Do not
cancel, delete, force-register, restart-as-new or erase history to obtain zero.

One Root-authorized registration, actual serving-process/socket attestation,
all-history replay and current boot/namespace/fence rechecks precede admission.
An unknown registration stays pending and cannot be retried. Restart or namespace
recreation must fail closed if Unix protection or retirement evidence is absent.
No shared Docker/Hermes/Bifrost/Stapled restart, candidate promotion or human
approval is authorized by this decision.

## Rejected alternatives

- Lock plus SQL count: old code and direct admin do not participate.
- SDK4-only retirement: SDK1–3 remain ungated execution targets.
- Direct-port UID filtering with8080 open: Restate can forward to old code.
- Immediate nft deployment: adds namespace capability/ruleset authority before
  testing the simpler supported Unix candidate. Keep it a fallback, not a second
  mandatory implementation.
- Widening private data permissions or broad DAC/ptrace/network capabilities:
  fixed PID1 execution under the existing trusted journal role avoids that need.
