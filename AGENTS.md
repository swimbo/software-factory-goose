# Project instructions

Be concise.

## Git hygiene

- Commit completed, verified milestones in coherent commits and push them to the upstream branch regularly.
- Push completed commits before ending a work session or handing off; report any push failure explicitly.
- Review staged files for secrets and unrelated changes. Keep credentials and runtime state out of Git.
- Preserve concurrent work. Do not rewrite shared history or force-push.
- Source publication does not authorize deployment, worker activation, or candidate promotion.
